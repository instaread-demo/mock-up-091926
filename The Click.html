Dying Light The Beast Call of the Beast Event Guide

ByWilliamP 17 September 2026
Listen to audio version of this article

Call of the Beast Event Guide for Dying Light: The Beast covers the three-week first anniversary event beginning on September 21, 2026. Techland is bringing back the Call of the Beast name for a shorter anniversary edition built around weekly global goals, community votes, changing weekend modifiers and special rewards linked to the Dying Light Outpost.

The anniversary celebrations actually begin before the main event. Update 1.7 arrived on September 17, a Double XP weekend starts on September 18, and the main Call of the Beast event follows on September 21. This Call of the Beast Event Guide separates those overlapping dates so you know what is active and when you need to check the Outpost.

Call of the Beast Event Guide: Dates and Schedule

Call of the Beast Event Guide Image Techland.

The Call of the Beast Event Guide starts with the event calendar. Call of the Beast: 1st Anniversary Edition runs for three weeks from September 21. Techland's anniversary roadmap places the event through October 12, with one weekly phase beginning on September 21, another on September 28 and the final week beginning on October 5.

How the anniversary Call of the Beast event works

The core of the Call of the Beast Event Guide is the weekly global goal. Players contribute together rather than completing a completely separate personal event track. Techland has not published the exact Week 1 action in the Update 1.7 notes, but it has confirmed that each week revolves around a shared goal and associated anniversary rewards.

There is also a voting system this time. During each week, players can vote on how they want to target enemies. The winning choice influences a special gameplay modifier for the weekend, changing how fights in Castor Woods play out. For this Call of the Beast Event Guide, that means the event is not just a progress bar. The community vote can alter the conditions you face later in the same week.

What happens during each of the three weeks

Each week of the Call of the Beast Event Guide follows the same broad loop: check the current global goal, contribute to it in game, visit the Outpost for event progress and rewards, and take part in the weekly vote. The detailed target can change from week to week, so it is worth checking the live event page at the start of each phase rather than assuming the previous objective still counts.

The three-week format is important to this Call of the Beast Event Guide because this is not a rerun of the original 2025 Call of the Beast campaign. That older event ran for eleven weeks and used a much larger chain of community goals. The 2026 anniversary edition is a separate three-week event with voting and weekend modifiers, so old challenge lists should not be treated as the current objectives.

Tougher enemies and rare Bober Infected

Update 1.7 also adds extra danger around the anniversary event. Techland says players can encounter tougher enemies as well as rare Bober Infected spawns. The release notes do not give a fixed spawn location, guaranteed spawn rate or a confirmed reward for killing a Bober Infected, so there is no reliable farming route to follow yet.

For now, the useful approach is to play normally while contributing to the active global goal and watch for the unusual infected during the event period. The Call of the Beast Event Guide will make more sense once the live weekly goal shows whether these rare spawns are directly tied to one of the challenge targets.

Double XP weekend comes first

The Double XP weekend runs from September 18, before Call of the Beast itself begins on September 21. It is part of the first anniversary celebrations, but it should not be confused with the three weekly global goals.

The Call of the Beast Event Guide treats that weekend as a preparation window, so it is a good opportunity to level before the event starts. You can use the bonus period to strengthen your character and prepare your equipment without worrying about missing the Call of the Beast goal, because the main event does not begin until September 21.

Crane's Anniversary Drops run alongside the event

A second reward system called Crane's Anniversary Drops begins on September 21. It is a 21-day web reward calendar on the Outpost Web Hub, running in parallel with Call of the Beast. Daily unlocks can include in-game dockets, store points and festive weapon skins with blueprints.

Missed daily rewards can still be claimed later, provided you do so before October 19 at 2:00 PM CEST. The Call of the Beast Event Guide keeps this separate from the weekly global goal system, so players who want everything from the anniversary need to keep an eye on both the Call of the Beast event page and the daily drops calendar.

What to do on September 21

When September 21 arrives, use the Call of the Beast Event Guide as your checklist: open the Dying Light Outpost and check the first live global goal before you start grinding. The exact weekly action is the one piece that Techland has deliberately left for the live event, so doing old 2025 challenge actions in advance will not bank progress for the new event.

The safest routine is simple: read the current goal, play Dying Light: The Beast and contribute to that action, check the community progress, cast the week's vote, then return for the weekend modifier and reward information. Following that loop is the easiest way to use this Call of the Beast Event Guide without wasting time on objectives that are no longer active.

For official game and anniversary information, you can also visit the Dying Light website.
